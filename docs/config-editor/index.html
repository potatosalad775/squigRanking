Config editor

1. Pick a rank style

2. Set the grades

Best first. Each step sets its own badge color and what the grade is worth, and the page derives the dropdown, the sort order and the chart from this one list.

  1. S
  2. A+
  3. A
  4. B+
  5. B
  6. C+
  7. C
  8. D+
  9. D
  10. F

3. Point it at your sheet

The URL comes from File → Share → Publish to web, with the format set to comma-separated values. One sheet can serve both types.

4. Choose your columns

Adds a parallel _KR column for each text block. A blank translated cell falls back to English, per row.

5. Name your page

These go in the config, not in index.html. That file is three empty landmarks the page fills in, so this is the only place the wording lives.

6. Take the file

Your sheet's header row should read: Brand, Model, Rank, Score, Driver, Style, Comment, Pros, Cons, Notes, Tags, Comment_KR, Pros_KR, Cons_KR, Notes_KR
